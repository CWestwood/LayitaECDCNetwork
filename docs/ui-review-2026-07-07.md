# Website UI review page-by-page (desktop version)

## Dashboard

- Overall Layout is good.
- Visits by type - "Other" gets its own row. The boxes should all be the same size, and ideally on the same row.
- Check all fonts are Railway across the site.
- Visits by Staff - A tabular format would be better for this information. "interested" and "other" both are lower case.
- Dates should all be in dd-mm-yyyy format across the whole site.

## My Work

- Don't show for administrators. Only for field staff (non-administrators).
- Unable to make more comments at this stage.

## Practitioners

- Some of the recent practitioner names are appearing as the UUIDs not the text name. This appears to be an issue on the supabase side as the practitioners already exist in the database with those UUIDs but new rows have been created with the UUIDs as the names...
- the "delete" buttons should be bin icons not the word "delete" in the practitioner cards
- the training a practitioner has received should ideally have a date attached to each training type - this will need an adjustment in supabase, and the frontend but can allow null values. This should then be editable by admin staff.
- "Save Changes" should result in a confirmation box showing the change made with a "Confirm" button. It should also trigger a background refresh of the data to show the change (currently the old data is shown until the page is reloaded).

## ECDCs

- Map looks great on desktop.
- Again some ECDCs have UUIDs for names instead of the actual name. Likely an edge function / Supabase issue.
- "Delete ECDC" on the cards should be the same icon as is used in the practitioner cards. With appropriate confirmation meessages.

- an option to view a table of the ECDCs in a similar style to the Practitioners page would be beneficial.
- add an "Add to planned outreach" button in the "Selected" options that then populates a planned outreach table on a "Outreach Planning" page. This should enable it to be assigned to a date and a staff member (non-administrators) (or person left blank). This function should exist for administrators only initially. [See Outreach Visits for more info].

## Outreach Visits

- More UUIDs instead of names.
- When a visit is selected and the card opens, there should be a delete option, and an option to view the raw Kobo data (presented in a tabular form) to allow it to be checked.
- Allow filtering by date range
- ALlow filtering by staff member.
- Add "Literacy Promotion" as a Type filter option
- Exclude "Update ECDC Details" from the shown visits as these are not visits
- Add a "View ECDC" and "View Practitioner" to get information regarding the ECDC/Practitioner (children/parents enrolled, contact numbers, etc).
- Add Bookdash books distributed, % attendance rate (parents trained / enrolled parents)
- Add book dash books distributed to children and to number of children (in brackets)
- Add bookdash books left with practitioner.

## Outreach Planning

- Create a new page for Outreach Planning where planned visits are shown and can be created.
- This should enable a form to be completed via the website with the planned date, practitioner/ecdc name, staff member assigned and outreach type.
- An export function should exist to allow for planned visits to be exported. This should include the contact details for the practitioners/ecdcs being visited.
- In the future, a link to a google calendar to allow for visits to be synced there will be added but not yet.

- Merge for simplicity.
